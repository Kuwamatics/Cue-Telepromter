Edit

Import a Word (.docx), text or Markdown file. Bold words in Word come through highlighted.

Put cues in square brackets, like [PAUSE], and they show in red. Wrap words in *stars* to highlight them. Leave a blank line to start a new paragraph.

Start a line with # to make a section you can jump to, like # Intro. For more than one speaker, start lines with the name in capitals, like ANNA:, and each person gets a colour.

Script assistant

Prompter

Speed is your reading pace in words per minute. Most presenters read at 130 to 170. Cues add a short beat, and [PAUSE] a longer one.

Type a length, like 1:30, and the speed is set so the script ends right on time.

Voice follow

Pick the language you'll speak. Voice follow has no time limit. If you improvise, it waits for you, and if you skip ahead it finds your place.

Readability
Presidential and second screens

Opens a left glass, a right glass and a confidence monitor. In Chrome and Edge each window moves to its own display. It also sets large, narrow lines that read well on glass. Click inside each window once to make it full screen. All screens stay in sync, and you control them from here, from the keyboard, or from your phone.

Using one monitor split to both glass panels? Open just the left glass.

Display settings stay on this device, so each rig keeps its own.

Recording

This browser blocks the camera and microphone here. Open SomaPrompt over HTTPS in Chrome, Edge or Safari to record.

With the camera behind the text, set the reading line near the top so your eyes stay close to the lens. A stronger backdrop makes the words easier to read.
